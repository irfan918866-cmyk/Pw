# PW GyanSarthi - PWA (Vercel Ready)

Progressive Web App (PWA) for **PW GyanSarthi Study Batches Portal**.

## Features Included
- 🚀 **Progressive Web App (PWA)**: Works on Android Chrome, iOS Safari, and Desktop Browsers.
- 📱 **1-Tap Add to Home Screen**: Includes `manifest.json` with PW icon and auto-install prompt.
- ☀️🌙 **Light & Dark Mode**: Floating toggle with automatic system theme sync and persistence.
- ⚡ **Offline Caching**: Built-in Service Worker (`sw.js`).
- 🎬 **Video & Lecture Player**: Supports fullscreen video playback.

---

## How to Deploy to Vercel (Choose any method):

### Method 1: Using Vercel CLI (Fastest, 30 seconds)
1. Open your terminal inside this folder:
   ```bash
   cd pwa-vercel
   ```
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the 2 prompts on screen. Your app will be live on a free `https://your-app.vercel.app` URL!

---

### Method 2: Using GitHub & Vercel Dashboard (Zero Setup)
1. Push this folder to your GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Set Root Directory to `pwa-vercel` (or root if uploaded alone).
5. Click **Deploy**!
